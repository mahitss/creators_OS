# Workflow Copilot Assistant Panel

## Interface Capabilities
- **Ask Vapor**: Accepts natural language requests (e.g., "Create a workflow that reviews important emails and prepares a response draft").
- **Visual Diff Viewer**: Displays node/edge additions, removals, capability changes, and risk deltas prior to acceptance.
- **Explain**: Summarizes workflow nodes, branches, and PolicyEngine capability access.
- **Debug**: Categorizes execution failures into 11 failure categories and suggests evidence-backed remediations.
- **Optimize**: Evaluates cost, performance, and safety optimizations.
- **Simulate**: Runs synthetic scenario tests.
- **Selected Node Actions**: Contextual actions for selected canvas nodes ("What does this do?", "Why is this failing?", "Make this safer").
