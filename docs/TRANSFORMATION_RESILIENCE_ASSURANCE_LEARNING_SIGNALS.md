# Learning Signals & Prioritization

## Learning Signal Types
Detects signals across:
- `outcome_variance`
- `failed_assumption`
- `unexpected_success`
- `unexpected_failure`
- `recurring_pattern`
- `calibration_error`
- `context_shift`
- `evidence_quality_change`

Prioritizes learning signals by decision impact, recurrence, severity, confidence, and generalizability.
