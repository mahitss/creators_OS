# Global Operations Center (`/operations`)

## Operations Center Dashboard
The Global Operations Center provides unified operational visibility and control:

1. **Executive Health Summary**: Top-level indicators for Overall System Health, Active Incidents, Security & DLP Boundary, and FinOps Spend.
2. **Subsystem Dependency Map**: Visual graph of major Vapor subsystems (`API`, `Agent Runtime`, `Workflow Engine`, `Event Mesh`, `Knowledge Fabric`, `Integration Fabric`, `Decision Intelligence`, `Policy Engine`, `PostgreSQL`, `Cache/Queue`).
3. **Control Action Gateway Dispatcher**: Policy-governed control action execution with risk assessment and 2-person approval gating.
4. **AI Operations Diagnostic Assistant**: Evidence-backed natural language operational query engine.
