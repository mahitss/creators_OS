# Enterprise Knowledge Fabric Architecture

## Core Flow
Source $\rightarrow$ Connector $\rightarrow$ Ingestion $\rightarrow$ Normalization $\rightarrow$ Parser $\rightarrow$ Document Representation $\rightarrow$ Chunking $\rightarrow$ Classification $\rightarrow$ Embedding $\rightarrow$ Index $\rightarrow$ Retrieval $\rightarrow$ Authorization Filter Gate $\rightarrow$ DLP Filter Gate $\rightarrow$ Rerank $\rightarrow$ Context Builder $\rightarrow$ Grounded AI Answer.

## Security Language Safeguard
Product UI and documentation use standard security control terminology (`Permission-aware retrieval`, `Grounded AI answers`, `Secure knowledge access`, `Policy-enforced retrieval`). Unverified claims ("Zero hallucinations", "100% secure retrieval") are prohibited.
