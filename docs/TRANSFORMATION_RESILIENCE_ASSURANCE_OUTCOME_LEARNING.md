# Decision Outcome Records & Expected vs Actual Variance

## Outcome Status Classification
Uses explicit status categories: `positive`, `mixed`, `negative`, `inconclusive`, `unknown`. Never infers outcomes from incomplete evidence.

## Expected vs Actual Comparisons
Compares separately:
- Expected vs Actual Risk Exposure
- Expected vs Actual Coverage
- Expected vs Actual Effort
- Expected vs Actual Timeline
- Expected vs Actual Capacity
- Expected vs Actual Residual Risk
