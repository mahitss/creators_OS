# Operating Model Change Proposals & Execution Lifecycle

`OperatingModelChangeProposal` formulates evidence-backed structural recommendations across 10 types (`clarify`, `standardize`, `delegate`, `centralize`, `decentralize`, `automate`, `integrate`, `remove_dependency`, `build_capability`, `increase_capacity`).

Material structural changes require explicit human leadership authorization (`Decision`, `Approval`, `PolicyEngine`) before execution via `Execution Governance` and `ActionGateway`.
