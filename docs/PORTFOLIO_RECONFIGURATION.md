# Portfolio Reconfiguration Proposals & Approval Lifecycle

`PortfolioReconfiguration` formulates evidence-backed recommendations across 9 types (`rebalance`, `accelerate`, `decelerate`, `pause`, `rescope`, `sequence_change`, `dependency_change`, `investment_shift`, `capability_shift`).

Every reconfiguration requires explicit leadership `Decision` and `Approval` through `PolicyEngine` before execution via `Execution Governance` and `ActionGateway`.
