# Enterprise Identity Architecture

## Pipeline Layering
Identity Provider $\rightarrow$ Authentication $\rightarrow$ Identity Normalization $\rightarrow$ Session $\rightarrow$ Organization Membership $\rightarrow$ Workspace Membership $\rightarrow$ Role $\rightarrow$ PolicyEngine $\rightarrow$ Resource Authorization $\rightarrow$ Audit.

## Security Language Safeguard
Product UI and documentation use standard identity control terminology (`Zero-trust authorization architecture`, `Supports OIDC`, `Supports SAML`, `SCIM provisioning`, `Enterprise identity controls`). Standard legal disclaimers prohibit unverified claims of "Zero Trust certified" or "SOC 2 certified".
