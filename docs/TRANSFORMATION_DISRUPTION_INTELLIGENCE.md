# Disruption Intelligence & Signal Validation

`TransformationDisruption` and `TransformationRecoveryImpact` track 11 disruption types (`dependency_failure`, `capacity_loss`, `technology_failure`, `vendor_failure`, `data_issue`, `governance_failure`, `execution_failure`, `benefit_failure`, `risk_event`, `scenario_shock`, `external_event`) across an explicit signal lifecycle (`observed`, `suspected`, `confirmed`, `resolved`).
