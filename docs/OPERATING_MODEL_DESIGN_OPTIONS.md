# Operating Model Design Options & Trade-off Frontier

`OperatingModelDesignOption` evaluates 11 option types (`centralize`, `decentralize`, `federate`, `platformize`, `standardize`, `automate`, `outsource`, `insource`, `integrate`, `simplify`, `reconfigure`).

`OperatingModelComparison` evaluates cost, speed, control, resilience, and complexity trade-offs, classifying designs into 4 categories (`dominated`, `competitive`, `high_upside`, `high_risk`).
