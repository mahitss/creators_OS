# Operational Control Guardrails & Breaches

`ControlGuardrail` enforces operational thresholds (`max_cost`, `max_risk`, `min_quality`, `max_delay`, `max_capacity`, `data_freshness`, `confidence`, `policy`).

`GuardrailBreach` logs threshold violations and triggers configured actions (`alert`, `recommend`, `escalate`, `pause`, `require_approval`).
