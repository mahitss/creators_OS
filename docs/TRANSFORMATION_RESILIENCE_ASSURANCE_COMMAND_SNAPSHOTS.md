# Command Snapshots & Point-in-Time Diffs

## Point-in-Time Operational Snapshots
Captures complete operational picture at a point in time for executive review, incident analysis, post-event comparison, and trend analysis.

## Automated Snapshot Diffs
Compares previous vs current snapshot, calculating `new_risks`, `resolved_risks`, `new_warnings`, `resolved_warnings`, `new_conflicts`, `resolved_conflicts`, `new_interventions`, `completed_interventions`, and `decision_changes`.
