# Knowledge, Plan & Transformation Health Projections

## Health Projections
Project real-time health across:
- **Knowledge Health**: evidence freshness, coverage, validation rate, review backlog, staleness, uncertainty score.
- **Plan Health**: plan health status, staleness, dependency health, risk exposure, execution status.
- **Transformation Health**: transformation risk score, coverage score, execution health, dependency health, active interventions count, residual exposure.
