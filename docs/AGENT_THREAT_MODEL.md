# Agent Threat Model & Attack Vectors

Vapor OS continuously evaluates agent operations against 15 threat vectors:

1. Prompt Injection
2. Indirect Prompt Injection
3. Tool Abuse & Parameter Manipulation
4. Agent Impersonation
5. Privilege Escalation
6. Credential Exposure & Secret Leakage
7. Data Exfiltration
8. Malicious Capabilities
9. Unsafe Agent Delegation
10. Memory Poisoning
11. Knowledge Poisoning
12. Supply-Chain Risks
13. Behavioral Anomalies
14. Policy Bypass Attempts
15. Cross-Tenant Data Access
