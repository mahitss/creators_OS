# Enterprise Performance Intelligence Engine

`PerformanceIntelligenceService` tracks KPI status (`on_track`, `watch`, `at_risk`, `off_track`, `unknown`) across 12 categories (`strategic`, `financial`, `operational`, `customer`, `quality`, `risk`, `capacity`, `delivery`, `security`, `AI`, `workforce`, `innovation`).

Supports multi-source provenance (`KPIDataSource`) and natural-language performance queries with DLP boundary enforcement.
