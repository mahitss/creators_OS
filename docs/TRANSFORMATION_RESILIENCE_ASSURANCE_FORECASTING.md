# Range Forecasting & Scenario Analysis

## Forecast Ranges
Presents forecasts as ranges to avoid false precision: `lower bound`, `central estimate`, `upper bound`.

## Scenario Types & Invalidation Conditions
Reuses existing Simulation to evaluate scenarios (`baseline`, `improving`, `deteriorating`, `shock`, `capacity_constrained`, `evidence_constrained`), tracking invalidation conditions (`signal disappears`, `trend reverses`, `new evidence arrives`, `dependency stabilizes`, `capacity increases`, `external condition changes`).
