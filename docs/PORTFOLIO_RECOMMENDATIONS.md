# Investment Options & Approval-Gated Recommendations

`PortfolioRecommendation` provides multi-option alternatives (`Option A`, `Option B`) with explicit trade-off matrices (cost, speed, risk, capacity, alignment) and reversibility ratings (`reversible`, `partially_reversible`, `irreversible`).

All material investment changes require explicit human approval via `Approval` and `PolicyEngine`. Vapor never moves capital automatically.
