# Agent Memory Taxonomy

Vapor OS Memory 3.0 categorizes memories into six distinct types:

1. **Episodic**: References actual events and execution milestones (`what happened`).
2. **Semantic**: Stable knowledge derived from evidence-backed observations.
3. **Procedural**: Versioned step-by-step procedures for recurring workflows.
4. **Working**: Ephemeral execution context.
5. **Preference**: User and workspace preferences (distinguishing explicit user input from inferred assumptions).
6. **Execution**: References execution runs, checkpoints, and step outputs.
