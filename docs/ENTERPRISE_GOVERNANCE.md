# Enterprise Governance Control Plane

## Architecture
Centralized, deterministic, auditable, least-privilege, and organization-aware governance control plane across IAM, RBAC, immutable audit logging, data retention, legal holds, access reviews, policy simulation, security findings, and compliance readiness.

## Compliance Language Safeguard
Product UI and documentation use control-readiness terminology (`Control mapping`, `Evidence collection`, `Compliance readiness`, `Supports control assessment`). Standard legal disclaimers prohibit unverified claims of "SOC 2 compliant" or "ISO 27001 certified".
