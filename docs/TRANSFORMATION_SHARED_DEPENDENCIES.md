# Enterprise Transformation Shared Dependencies

## Shared Dependency Concentration

Vapor detects dependencies shared across multiple transformation waves, programs, and portfolios.

## Key Analysis Areas
* **Vendor Concentration**: Multiple waves depending on a single third-party provider.
* **Technology Concentration**: Multiple systems bottlenecked on a central OAuth API gateway.
* **Capability & Data Concentration**: Shared data pipelines or identity federation gateways.
* **Substitution Options**: Feasibility scoring for active-active redundant routes.
