# Transformation Roadmaps & Workstream Execution

`TransformationRoadmap` and `TransformationWorkstream` structure transformation execution across 7 phases (`diagnose`, `design`, `pilot`, `transition`, `scale`, `stabilize`, `optimize`).

Maps workstreams across 8 structural types (`organization`, `process`, `technology`, `data`, `governance`, `capability`, `decision_rights`, `change_management`).
