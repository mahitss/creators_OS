# Expected vs Actual Variance Analysis

`TransformationDecisionExpectedOutcome`, `TransformationDecisionActualOutcome`, and `TransformationDecisionVariance` compare projected vs observed metrics across 9 variance types (`benefit`, `cost`, `timing`, `risk`, `capacity`, `quality`, `adoption`, `dependency`, `strategic`) and 4 materiality levels (`minor`, `moderate`, `material`, `critical`).
