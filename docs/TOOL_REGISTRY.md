# Vapor OS — Typed Tool Registry Architecture

## Safe Read-Only Tools
1. `search_missions`: Search active/completed workspace missions.
2. `get_mission`: Retrieve single mission details.
3. `search_memory`: Search approved long-term memories.
4. `get_calendar_events`: Search upcoming calendar commitments.
5. `search_gmail`: Search read-only email metadata.
6. `get_gmail_message`: Read single email message.
7. `search_drive_files`: Search Google Drive file metadata.
8. `get_drive_file_content`: Extract text from Google Docs or PDF documents.
9. `search_content`: Search Studio Content Canvas documents.
