## Overview & Systemic Intelligence Pipeline

Vapor OS Sprint 104 builds the cross-domain intelligence layer above Sprints 99-103:

```
DOMAIN SIGNALS → CROSS-DOMAIN RELATIONSHIP → RESILIENCE GRAPH → PROPAGATION ANALYSIS → SYSTEMIC EXPOSURE → SCENARIO → EARLY WARNING → INTERVENTION OPTIONS → GOVERNANCE → COMMAND CENTER → LEARNING
```

## Core Principle
Cross-domain intelligence MUST explain relationships showing `source`, `relationship`, `propagation_path`, `affected_objects`, `evidence`, `confidence`, `uncertainty`, and `possible_intervention_point`. Never creates an unexplained single "systemic risk score".
