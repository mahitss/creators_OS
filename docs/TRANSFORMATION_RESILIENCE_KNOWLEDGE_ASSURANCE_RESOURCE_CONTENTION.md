# Resource Demand & Resource Contention Detection

## Resource Types
Tracks resources without individual employee performance scoring:
- `expert`
- `evidence_source`
- `dataset`
- `simulation_capacity`
- `review_capacity`
- `remediation_capacity`
- `decision_window`
- `governance_attention`

## Contention Severity
Classified into: `informational`, `low`, `medium`, `high`, `critical`.
