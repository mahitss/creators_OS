# Enterprise Transformation Resilience Priority Queue

## Executive Priority Ranking Logic

Prioritizes items needing executive attention based on visible, explainable dimensions:
* **Impact Score**: Potential blast radius across transformation programs.
* **Urgency Score**: Time remaining before structural degradation manifests as failure.
* **Confidence Rating**: Underlying evidence reliability.
* **Scope**: Transformations and waves affected.
* **Reversibility**: Effort required to roll back decisions.
* **Decision Deadline**: Hard governance deadline for executive review.
