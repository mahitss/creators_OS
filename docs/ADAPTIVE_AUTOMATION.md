# Adaptive Automation & Performance Telemetry

## Telemetry Profiling & Bottleneck Analysis
Aggregates execution metrics (`execution_count`, `success_rate`, `p50_latency`, `p95_latency`, `average_cost`, `retry_rate`, `approval_wait_time`). Identifies execution bottlenecks (`latency`, `cost`, `failure`, `retry`, `queue`, `provider`, `approval`, `sequential_dependency`, `data_transfer`) backed by concrete execution evidence.
