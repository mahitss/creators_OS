# Future Operating Models & Target State Blueprints

`FutureOperatingModel` formulates target operating model blueprints (`program_id`, `name`, `description`, `design_principles_json`, `constraints_json`, `assumptions_json`, `target_capabilities_json`, `target_processes_json`, `target_decision_rights_json`, `target_dependencies_json`).

Allows multiple future operating models simultaneously without forcing a single rigid answer.
