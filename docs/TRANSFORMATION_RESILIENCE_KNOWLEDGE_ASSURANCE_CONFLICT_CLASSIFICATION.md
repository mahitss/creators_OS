# Conflict Classification & Root Cause Analysis

## Conflict Types
Classifies conflict cases into:
- `resource`
- `deadline`
- `dependency`
- `evidence`
- `review`
- `simulation`
- `governance`
- `risk`
- `coverage`
- `execution`
- `capacity`
- `scope`

## Root Cause Categories
Groups root causes across `shared_resource`, `incompatible_deadline`, `shared_evidence`, `dependency_ordering`, `governance_constraint`, `capacity_shortage`, `scope_overlap`, and `assumption_divergence`.
