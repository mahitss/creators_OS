# Vapor OS — Context Engine Source Taxonomy & Adapters

## Source Taxonomy
1. `mission`: Active workspace missions and step plans.
2. `memory`: Approved long-term memories only.
3. `content`: Studio Content Canvas articles.
4. `calendar`: Google Calendar commitments (-7 to +30 days).
5. `gmail`: Read-only email threads/messages.
6. `drive`: Google Drive file metadata and attached documents.
7. `attention`: Active attention inbox items.
8. `mission_result`: Execution engine step results.
