# Vapor OS — Member Roles & Permission Matrix

| Role | Workspace Read | Workspace Update | Member Management | Mission Creation | Agent Write Execution | Approval Authority |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Owner** | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| **Admin** | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| **Member** | ✅ | ❌ | ❌ | ✅ | ✅ | ✅ |
| **Viewer** | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ |

`Viewer` roles are strictly restricted to read-only capabilities and cannot approve external side-effect tool executions.
