# Governed Resilience Decision Operating System 2.0

## Overview & Architecture

Vapor OS Sprint 91 converts resilience intelligence into a structured, traceable, human-governed decision lifecycle:

```
SIGNAL → SITUATION → EVIDENCE → DECISION QUESTION → OPTIONS → SCENARIOS → TRADE-OFFS → RECOMMENDATION → DECISION → APPROVAL → EXECUTION → VERIFICATION → OUTCOME → LEARNING
```

## Critical Governance Principles
* **Human Decision Authority**: Vapor provides decision support. Humans retain decision authority.
* **Agent Restrictions**: Agents may detect, frame, collect evidence, simulate, compare options, draft recommendations, prepare packets, and verify, but CANNOT autonomously approve, reject, fund, execute material changes, or override decision owners.

## Sprint 92 Closed-Loop Decision Learning Integration
Feeds executed decisions and live verification outcomes into [TRANSFORMATION_RESILIENCE_DECISION_LEARNING.md](./TRANSFORMATION_RESILIENCE_DECISION_LEARNING.md) to close the learning loop, calibrate simulation models, and validate future decision precedents.
