# Plan Variance, Deviations & Root Cause Hypotheses

`TransformationPlanVariance`, `TransformationDeviation`, and `TransformationRootCauseHypothesis` detect metric deviations across 10 variance types (`schedule`, `scope`, `cost`, `capacity`, `dependency`, `risk`, `benefit`, `quality`, `governance`, `adoption`) and generate evidence-backed diagnostic hypotheses with alternative explanations.
