# Transformation Resilience Decision Options Analysis

## Option Evaluation Types
Supports structured evaluation across:
* `maintain_current`
* `invest`
* `diversify`
* `add_redundancy`
* `increase_capacity`
* `change_sequence`
* `change_recovery_path`
* `defer`
* `alternative`

Tracks benefits, risks, capital cost, capacity impact, dependencies, reversibility, and optionality scores.
