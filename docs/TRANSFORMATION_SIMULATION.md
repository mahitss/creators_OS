# Multi-Layer Transformation Simulation Engine

`TransformationSimulationRun` executes validated change sets (`TransformationSimulationChangeSet`) against baseline states, producing low/expected/high output ranges (`TransformationSimulationOutput`) with cryptographic hash fingerprints (`hash_fingerprint`).
