# Enterprise Transformation Resilience Trends

## Trend Trajectory Monitoring

Tracks directionality of resilience across 7 discrete dimensions (robustness, redundancy, recoverability, adaptability, optionality, observability, governability).

## Time Windows
Supports flexible analysis windows: 7d, 30d, 90d, 180d, 365d, and custom periods. Trend classifications: `improving`, `stable`, `deteriorating`, `volatile`, `insufficient_data`.
