# Graph Security, DLP & Authorization Traversal

## Authorization Filtering
Every traversal query evaluates user identity, organization scope, workspace scope, and explicit resource access controls. Graph edges NEVER bypass underlying authorization rules.

## DLP & Sensitive Personal Data
Graph metadata strictly prohibits inferring or constructing edges for sensitive personal traits (health, religion, political affiliation, race/ethnicity, sexual orientation). Personal data is minimized to entity IDs and metadata references.
